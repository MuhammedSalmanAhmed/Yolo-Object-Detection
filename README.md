# Duck Hunt Object Detector 🦆

An object detection application built using YOLOv8n and Streamlit.

## Detected Classes
- dog
- duck_dead
- duck_shot
- duck_flying

## Model Performance
- Precision: 99.43%
- Recall: 99.42%
- mAP50: 99.50%
- mAP50-95: 93.68%

## Technologies
- Python
- Ultralytics YOLOv8
- Streamlit
- PyTorch
